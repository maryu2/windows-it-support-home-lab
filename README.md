# Windows IT Support Troubleshooting Home Lab

## Overview

A hands-on Windows troubleshooting lab created to develop practical IT Support skills.

The lab uses a Windows virtual machine running in VirtualBox.

## Tools

- Windows 11
- VirtualBox
- PowerShell
- Command Prompt
- Event Viewer
- Device Manager
- Task Manager
- Windows Services
- GitHub
- Markdown

## Troubleshooting Labs

1. User account troubleshooting
2. Network troubleshooting
3. DNS troubleshooting
4. Windows service troubleshooting
5. Disk space troubleshooting
6. Windows permissions
7. Software troubleshooting
8. Event Viewer investigation
9. Device/driver troubleshooting
10. Printer troubleshooting
